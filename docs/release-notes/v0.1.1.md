Auto Login for NinjaTrader signs in to NinjaTrader 8 on Windows and selects Simulation or Live. It does not place orders or enable strategies.

## Changes since 0.1.0

**New NinjaTrader versions**

- NinjaTrader 8.1.9.0 is tested, through the desktop shortcut and by watching NinjaTrader launches.
- A newer NinjaTrader no longer needs an app update. Its first successful sign-in confirms it on your computer, and the app stops mentioning it. Until then, a shortcut sign-in shows a quiet line in its progress window, watching shows no notice or sound, and Live asks once for that version.

**Diagnostics**

- When a sign-in stops, the local run record now shows which NinjaTrader windows were open, by type only, where the error came from, as method names, and how many NinjaTrader processes were running. No window titles or other text are read. The support summary includes the error location and the process count.

**Documentation**

- Checking the download is now a step before opening the app, with what each check shows.

## Before you use it

- **Tested:** Simulation sign-in on NinjaTrader 8.1.8.4 and 8.1.9.0, through the desktop shortcut and by watching NinjaTrader launches.
- **Not tested:** Live sign-in with a real account. Selecting Live asks for confirmation, and an account without Live stops without opening an account page.
- **Your responsibility:** read the [legal notice](https://github.com/MohZeh/Auto-Login-for-NinjaTrader#legal-notice). NinjaTrader's license restricts bypassing security protections and allows access to be suspended after a breach. Decide for yourself whether you may use this app.

## Install

1. Download `NinjaTraderAutoLogin-0.1.1-win-x64.zip` and its `.sha256` file.
2. Check the download as shown below, before opening anything.
3. Extract the whole folder and open `NinjaTraderAutoLogin.exe`. It is not code-signed, so Windows SmartScreen may warn you. Only after the checks pass, select **More info**, then **Run anyway**.
4. Enter your details and save.

Upgrading from 0.1.0: exit the app, replace the folder with the new one, and open it once from its place. Settings and the saved password stay as they are.

## Verify the download

Is the file complete and unchanged? Compare the result with the `.sha256` file:

```powershell
Get-FileHash .\NinjaTraderAutoLogin-0.1.1-win-x64.zip
```

Was it built by this project? This is GitHub's signed record of the release workflow:

```powershell
gh attestation verify .\NinjaTraderAutoLogin-0.1.1-win-x64.zip --repo MohZeh/Auto-Login-for-NinjaTrader
```

To rebuild it yourself, check out tag `v0.1.1`, run `./build.ps1` with .NET SDK 10.0.403, and compare the SHA-256 it prints with `NinjaTraderAutoLogin.exe` from the ZIP.
