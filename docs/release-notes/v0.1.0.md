First stable release of Auto Login for NinjaTrader, a Windows app that signs in to NinjaTrader 8 and selects Simulation or Live. It does not place orders or enable strategies.

## Changes since 0.1.0-rc.1

- The release executable is reproducible. Building tag `v0.1.0` with .NET SDK 10.0.403 gives the same `NinjaTraderAutoLogin.exe` as the one in the ZIP. The app's behavior is unchanged.

## Before you use it

- **Tested:** Simulation sign-in on NinjaTrader 8.1.8.4, through the desktop shortcut and by watching NinjaTrader launches.
- **Not tested:** Live sign-in with a real account. Selecting Live asks for confirmation, and an account without Live stops without opening an account page.
- **Other NinjaTrader versions:** Simulation continues with a notice. Live asks once for each untested version.
- **Your responsibility:** read the [legal notice](https://github.com/MohZeh/Auto-Login-for-NinjaTrader#legal-notice). NinjaTrader's license restricts bypassing security protections and allows access to be suspended after a breach. Decide for yourself whether you may use this app.

## Install

1. Download `NinjaTraderAutoLogin-0.1.0-win-x64.zip` and extract the whole folder.
2. Open `NinjaTraderAutoLogin.exe`.
3. Enter your details and save.

The executable is not code-signed, so Windows SmartScreen may warn you. To continue, select **More info**, then **Run anyway**, if you trust this source.

## Verify the download

Compare the ZIP with the published `.sha256` file:

```powershell
Get-FileHash .\NinjaTraderAutoLogin-0.1.0-win-x64.zip
```

Confirm that GitHub built it from this repository:

```powershell
gh attestation verify .\NinjaTraderAutoLogin-0.1.0-win-x64.zip --repo MohZeh/Auto-Login-for-NinjaTrader
```

To rebuild it yourself, check out tag `v0.1.0`, run `./build.ps1` with .NET SDK 10.0.403, and compare the SHA-256 it prints with `NinjaTraderAutoLogin.exe` from the ZIP.
