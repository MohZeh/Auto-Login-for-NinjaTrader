Auto Login for NinjaTrader signs in to NinjaTrader 8 on Windows and selects Simulation or Live. It does not place orders or enable strategies.

## Changes since 0.1.1

**Password safety**

- The app now records each sign-in attempt before the password is sent. If the app, its sign-in process or the computer stops before NinjaTrader answers, the next sign-in does not send the password again on its own. It asks *Try the same password again?* first.
- The same applies when NinjaTrader shows a message that needs you after the password was sent, because that message may be the refusal itself.
- The warning for a held password now reads *Sign-in didn't complete: password, connection or a stop.*, since it also covers an attempt that stopped before its answer.

**Reliability**

- A NinjaTrader message window that stays open for 10 seconds during sign-in now stops with *NinjaTrader needs your attention. Continue manually in its window.*, instead of waiting for the two-minute limit.
- Waits are timed by elapsed time, so changing the Windows clock during a sign-in no longer shortens or lengthens them.
- Fixed a rare stop with *The operation could not finish.* before the password was sent. The progress window's reading of the sign-in record could block the app from updating that record.

**Testing**

- Each change is now also checked end to end: the real sign-in process reads a test password from Windows Credential Manager and signs in to a test window that imitates NinjaTrader. This runs in a separate test build. The released app contains none of its code.

## Before you use it

- **Tested:** Simulation sign-in on NinjaTrader 8.1.9.0, through the desktop shortcut and by watching NinjaTrader launches. Version 0.1.1 was also tested on 8.1.8.4.
- **Not tested:** Live sign-in with a real account. Selecting Live asks for confirmation, and an account without Live stops without opening an account page.
- **Your responsibility:** read the [legal notice](https://github.com/MohZeh/Auto-Login-for-NinjaTrader#legal-notice). NinjaTrader's license restricts bypassing security protections and allows access to be suspended after a breach. Decide for yourself whether you may use this app.

## Install

1. Download `NinjaTraderAutoLogin-0.1.2-win-x64.zip` and its `.sha256` file.
2. Check the download as shown below, before opening anything.
3. Extract the whole folder and open `NinjaTraderAutoLogin.exe`. It is not code-signed, so Windows SmartScreen may warn you. Only after the checks pass, select **More info**, then **Run anyway**.
4. Enter your details and save.

Upgrading from 0.1.0 or 0.1.1: exit the app, replace the folder with the new one, and open it once from its place. Settings and the saved password stay as they are.

## Verify the download

Is the file complete and unchanged? Compare the result with the `.sha256` file:

```powershell
Get-FileHash .\NinjaTraderAutoLogin-0.1.2-win-x64.zip
```

Was it built by this project? This is GitHub's signed record of the release workflow:

```powershell
gh attestation verify .\NinjaTraderAutoLogin-0.1.2-win-x64.zip --repo MohZeh/Auto-Login-for-NinjaTrader
```

To rebuild it yourself, check out tag `v0.1.2`, run `./build.ps1` with .NET SDK 10.0.403, and compare the SHA-256 it prints with `NinjaTraderAutoLogin.exe` from the ZIP.
